Radiology Report Summarisation API

Overview: An end-to-end machine learning system that fine-tunes Google's FLAN-T5-base model on the NLM Chest X-ray dataset to automatically generate concise clinical impressions from radiology findings text.

What it does: A clinician pastes chest X-ray findings into the web interface, and the model generates a concise clinical impression — the diagnostic summary that would normally be written manually.

Key achievements:

  • Fine-tuned FLAN-T5-base on 3,419 chest X-ray report pairs
  • BERTScore F1 of 0.866 — demonstrating strong semantic accuracy
  • Fully reproducible script-based pipeline (preprocess → train → evaluate)
  • Live REST API deployed on HuggingFace Spaces with Docker
  • Browser-based frontend for non-technical users

Tech Stack:

Python FLAN-T5-base HuggingFace Transformers PyTorch FastAPI Docker BeautifulSoup Pandas BERTScore ROUGE Google Colab HuggingFace Spaces Git
Live Demo GitHub Repository
Visual Product Recommender

Overview: An image-based fashion recommendation system that uses CLIP embeddings and cosine similarity to find visually similar clothing items from a dataset of over 31,000 unique product images.

What it does: A user uploads a clothing image and the system returns the top 5 most visually similar items from the product catalogue, each with a cosine similarity score above 0.93.

Key achievements:

  • Cleaned 50,292 images to 31,376 unique images by removing duplicates and degenerate placeholders
  • Generated 512-dimensional CLIP embeddings for all 31,376 images
  • Achieved cosine similarity scores of 0.93-0.96 on test images, well above the 0.7 threshold
  • Generated 300x300 thumbnails reducing deployment size from 4GB to 314MB
  • Deployed as a live Streamlit web app with image upload and recommendation display
